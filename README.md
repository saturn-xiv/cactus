# CACTUS - Webhooks server for Gogs & Github

## Usage

    ```bash
    git clone https://github.com/saturn-xiv/cactus.git $HOME/workspace/cactus
    cd $HOME/workspace/cactus/
    ./build.sh
    ```

## Deployment

    ```bash
    cactus -d http -p 10002 -c config.toml
    ```
